# Subsystem Evidence

Raw output from canonical validation runs. **Not summaries** — the whole point is
that a claim about a subsystem can be checked against what actually happened.

Each run lands in `s0N-<UTC timestamp>/` and contains environment provenance,
quality-gate output, full verbose test results, migration logs and benchmark
numbers. Directories are append-only; a re-run creates a new one.

Generated by `scripts/canonical_validation.sh`.
