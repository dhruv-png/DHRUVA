## Dependency changes

**None.** S03 introduced no runtime dependency. `mutmut` was evaluated and could
not run (see TD-12); it is not in the dependency set.

## Migration notes

**No migration required.** Verified, not assumed:

- **No database schema.** S03 defines types; S04 defines persistence. The
  persistence contract each type must satisfy is specified in the design document
  so S04 inherits it: `Money` → `BIGINT` + `CHAR(3)`; `Price` → `BIGINT` at
  8 dp; `Quantity` → `INTEGER`; `TradingDay` → `DATE`; `InstrumentId` → `UUID`.
- **No configuration change.** No new environment variables.
- **No breaking API change.** Nothing outside the shared kernel consumed these
  types before this release, because they did not exist.

## Rollback procedure

```bash
cd DHRUVA
git checkout v0.2.0
cd backend && uv pip install --require-hashes -r requirements-dev.lock
cd .. && make check
```

**What rollback does not undo:**

| Item | Reversible? | Notes |
|---|---|---|
| Source and tests | **Yes** | `v0.2.0` is a green tag |
| Dependency set | **Yes** | Unchanged by this release |
| Database state | **N/A** | S03 touches no database |
| **ADR corpus** | **No** | ADR-042 … ADR-050 are accepted and immutable. ADR-005 is superseded and stays superseded — rolling back code does not un-decide it. |
| **API stability commitment** | **No** | ADR-050 binds from acceptance, not from deployment |

There is no in-flight state, no queue, no external side effect. Rollback remains
a `git checkout` — which stops being true at S04, when Alembic migrations arrive.

## Known limitations

Full register in the design document §12. Highest priority:

- **TD-12 (HIGH)** — mutation testing did not run. Three tooling routes blocked;
  commands supplied for a machine without a per-command time ceiling.
- **TD-01 / TD-02 (HIGH)** — canonical `uv.lock` and validation on Python 3.12,
  both blocked on the same trigger.
- **TD-15 / TD-16 / TD-17 (ACCEPTED)** — reachable bare `TradingDay` constructor,
  `Decimal` in the rate path, no currency conversion.
