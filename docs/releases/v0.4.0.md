## Summary

The layer that turns domain objects into rows and back. Everything from here on
stores something, so the cost of getting this wrong compounds.

Approved with the benchmark budgets deferred to ADR-060: five budgets were over
on the Windows development environment and none was verified on the deployment
target. No threshold was relaxed — they are recorded as *unverified*, and
ADR-060's amendment A1 makes the Linux CI benchmark job a stop-the-line item
before S06.

## What shipped

- **Async persistence stack.** SQLAlchemy 2 async engine, a `UnitOfWork` owning
  the transaction (ADR-053), `DailySnapshotRepository` as the worked example, and
  a four-layer mapping — domain ← factory ← record ← model ← row — keeping the
  domain persistence-ignorant (ADR-052).
- **Transactional outbox.** `OutboxWriter` stages events inside the caller's
  transaction, so an event and the change that caused it share one fate.
- **The ORM-bypass write path** (ADR-054). `PostgresTimeSeriesStorage` appends
  allowlisted column rows with asyncpg `COPY`. No update, no delete, no lookup by
  identity — the interface enforces the exception rather than describing it.
  Boundary rule R8 fails the build if anything in that package imports a domain
  layer.
- **Optimistic concurrency** via a `version` column, surfacing a `ConflictError`
  naming the version it expected (ADR-057).
- **Integration suite against real PostgreSQL** (ADR-058).

## Dependency changes

`sqlalchemy==2.0.44`, `alembic==1.16.5`, `asyncpg==0.30.0`, `tzdata==2025.2`
added as runtime dependencies; `testcontainers` added for development. Each is
recorded in the provenance map that `test_toolchain_config.py` enforces.

## Migration notes

Migrations `0001_initial` and `0002_example_tick`, each declaring its
reversibility, rollback procedure and operational impact (ADR-055).

## Rollback procedure

`alembic downgrade base` reverses both migrations. Neither is destructive of
data the platform cannot reconstruct at this stage, because nothing outside the
worked example writes yet.

## Known limitations

- **Five performance budgets unverified on the deployment target** (ADR-060).
  This is the stop-the-line item before S06.
- **Mutation testing not run** (TD-12).
- **`event_version`, `correlation_id` and `causation_id` land nullable.** The
  expand step only; the contract step making them NOT NULL is TD-S05-7.
- **The outbox has no relay.** The process that drains it arrives in S05, so at
  this tag events are durable and undelivered — which is the intended state, not
  an omission.
