# Frontend

Next.js, TypeScript, TailwindCSS, TanStack Query, TradingView Lightweight Charts.

**Not yet built.** The frontend arrives with the thin MCP dashboard slice at the
end of Stage 1 (plan §9.3), and in full with S37-S39 in Stage 2.

Two modes are planned, over **one** API (ADR-019): Simple Mode — large type, high
contrast, plain English, traffic-light semantics, WCAG 2.2 AA — and Professional
Mode — multi-pane, option chain, OI and gamma exposure, volatility dashboard.
Accessibility is a baseline for both, not a third mode.
