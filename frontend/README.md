# Frontend

**Not yet built.**

The approved roadmap places the household UI after the evidence clock,
historical/evaluation foundation, candidate ranking, risk layer and household
HTTP API. The intended client is a small private React + TypeScript + Vite
single-page application for Dhruv and Dad. Final UI libraries will be chosen in
that slice from repository requirements rather than inherited from the deferred
institutional roadmap.

It will expose evidence, risk and explanations for human decisions. It will not
add automated trading or present the current attention heuristic as an
investment recommendation. Accessibility remains a baseline requirement.
